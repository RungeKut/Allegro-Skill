# Работа с репозиторием

Набор — `https://github.com/RungeKut/Allegro-Skill`, ветка `main`.
**Порядок, обезличивание, стоп-лист, автор, соавторы, GitHub без gh, форк
и разбор PR — соседний скилл skill-skill, `knowledge/40_СРЕДА/40-02` и
40-03.** Коротко: в начале `git -C <корень> pull --rebase`; после правки
`git diff` глазами → `python tools/check_docs.py --project "<папка
проекта>"` → `git add <файлы>` → `git commit` → **`git push` сразу**.

## Обезличивание: плата и схема

Репозиторий **публичный**. Кроме общего списка, в файлы, текст коммита и
PR не попадает:

* название изделия, децимальный номер, номер платы и схемы, имена файлов
  проекта;
* обозначения, имена цепей, номиналы и корпуса, если они характерны;
* числа изделия: сколько компонентов и цепей, размер контура, число
  слоёв, координаты;
* надписи шелкографии, **картинки платы** (`ak.png`) и снимки окон
  Allegro — их место `tests/vyvod/` или папка проекта, не под git.

**Остаётся**: поведение инструмента, командные строки, коды, примеры на
демонстрационных платах из поставки Cadence или на отвлечённой
«шестислойной плате». Описание узла, по которому изделие узнаётся без
названия, не ловит никакая проверка — за этим `git diff` глазами.

## Папка проекта для стоп-слов

`--project "<папка>"` и `git config allegro.project "<папка>"` добавляют к
стоп-словам имя папки проекта и имена лежащих в ней плат и схем (`.brd`,
`.dsn`, `.opj`, `.sch` и т. п. — `tools/kit_local.py`); конфиг учитывают
и `check_docs.py`, и общий хук. До 2026-10-28 ключ назывался
`alkit.project` — на старых клонах переименовать.
