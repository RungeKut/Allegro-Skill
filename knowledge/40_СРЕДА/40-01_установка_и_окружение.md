# Установка и окружение

## Клон

Общий порядок (папка скиллов агента, хук, автор, стоп-лист, обновление) —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-01`. Для этого набора:

```bash
git clone https://github.com/RungeKut/Allegro-Skill.git "<папка скиллов>/allegro"
cd "<папка скиллов>/allegro"
git config core.hooksPath ../skill-skill/hooks
git config user.name  "<публичное имя>"
git config user.email "<публичный адрес>"
python -m pip install --user Pillow      # картинки платы, снимки диалогов
python tools/check_docs.py
```

Несколько агентов (Claude Code, Kimi Code, opencode) — **по клону в папку
скиллов каждого агента**, имя папки `allegro`; клоны сходятся через
GitHub (skill-skill, 40-01). Обновление — `git pull --rebase` в клоне.

Своего стоп-листа набору можно не заводить — хватает общего; приметы
изделий этой машины — в общий или в `tools/stoplist.txt` (локальный).

## Зависимости

| Что | Где | Зачем |
|---|---|---|
| Cadence SPB 17.2-2016, hotfix S066 | `C:\Cadence\SPB_17.2` (ищется, не зашит) | Allegro, утилиты, tclsh, документация |
| Python 3.13, **64-bit** | любой | библиотека `alkit` |
| Pillow | `python -m pip install --user Pillow` | картинки платы (`ak.png`), снимки диалогов (`Live.snapshot`); без него — ошибка с этой командой |
| pywin32 | не нужен | окна и сообщения — через `ctypes` |

Проверка окружения:

```python
import sys
sys.path.insert(0, r"<корень набора>")
import alkit as ak
ak.utf8_console()
print(ak.__version__, ak.cdsroot(), ak.version(), ak.product_order())
```

Корень Cadence ищется так: `ALKIT_CDSROOT` → `CDSROOT` →
`Sigrity_EDA_DIR` (её прописывает установщик SPB) → `C:\Cadence\SPB_*`.

## Переменные Cadence

Набор сам себя не ищет по переменным: корень — папка `SKILL.md`, в коде —
от `__file__` (skill-skill, 30-01). Переменные ниже — только о Cadence,
все необязательны:

| Переменная | Что | По умолчанию |
|---|---|---|
| `ALKIT_CDSROOT` | корень Cadence, если поиск не нашёл | поиск |
| `ALKIT_PRODUCT` | лицензии для пакетного режима, через запятую | `Allegro_performance, Allegro_Venture_PCB_Designer` из числа доступных |
| `ALKIT_WORK` | рабочие папки заданий; только ASCII, без пробелов | `%LOCALAPPDATA%\Temp\alkit` |

Лицензионный сервер задаёт установка Cadence (`CDS_LIC_FILE`), набор его
не трогает. Кэш доступных уровней —
`%HOME%\pcbenv\license_cache_allegro_17.2-2016.txt`
([30-06](../30_ГРАБЛИ/30-06_лицензии.md)).

## Что где в установке Cadence

| Путь | Что |
|---|---|
| `tools\bin\allegro.exe` | Allegro PCB Editor; `-nographic` работает и на Windows |
| `tools\bin\report.exe`, `artwork.exe`, `ipc2581_out.exe`, `step_out.exe`, `pdf_out.exe`, `dbdoctor.exe`, `extracta.exe` | утилиты над файлом платы ([10-04](../10_API/10-04_утилиты_отчёты_и_экспорт.md)) |
| `tools\bin\tclsh.exe`, `orDb_Dll_Tcl64.dll` | чтение схем Capture ([10-03](../10_API/10-03_схемы_capture_через_tcl.md)) |
| `share\pcb\examples\wm_copydata\allegro_sendcmd.c` | пример живого канала ([10-02](../10_API/10-02_живой_режим_wm_copydata.md)) |
| `share\pcb\examples\skill\` | примеры AXL-SKILL от Cadence |
| `share\orcad\examples\pcbdesign\pcbdemo1\` | демо-пара `DEMOJ.Dsn` + `allegro\DEMOJ-complete.brd` — на ней идут `tests\` |
| `doc\algroskill\` | справочник AXL (HTML), глава 2 — атрибуты объектов |
| `doc\sklangref\` | язык SKILL |

Документация — HTML на тысячи страниц; для поиска её удобно один раз
перевести в текст (регулярка по тегам) и искать `grep`.

## История

До 2026-10-28 набор ставил `tools/setup.ps1` (и `Install-skill.bat`):
junction из папок скиллов Claude Code и Kimi Code в `<корень>\skill`
(для opencode — отдельной командой `mklink /J`), переменная `ALKIT_HOME`,
хук `tools/hooks`, локальный стоп-лист, проверка Python 64-bit и
установка Pillow. Отказались: клон и есть папка скилла, переменная
переживает перенос клона и ведёт в пустоту (skill-skill, 30-01). Что
стало с обязанностями установщика: хук и стоп-лист — общие, в
skill-skill; Pillow — командой выше и понятной ошибкой в `alkit`; Python
64-bit и Cadence — проверкой окружения выше.

Наблюдения той схемы, ещё полезные (2026-10-02, Windows 10, PowerShell
5.1):

* opencode требует, чтобы `SKILL.md` лежал прямо в папке скилла, а `name`
  совпадал с её именем (строчная латиница, 1–64 знака);
* `description` с «: » без кавычек — скилл молча пропадает из списка
  агента (skill-skill, 30-06); у `allegro` описание — 925 знаков из 1024,
  формулировку править осторожно;
* без прав администратора и Developer Mode символические ссылки на файлы
  не создаются — только junction (папки) и hardlink (файлы); PowerShell
  5.1 не заходит в junction при `Get-ChildItem -Recurse` (нужен
  `-FollowSymlink` из PowerShell 6+), пустой вывод не значит, что
  junction сломан — проверять `Test-Path` на конкретный файл.
