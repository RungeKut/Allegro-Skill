# Сборка платы из нетлиста без Capture

Порядок: падстеки и символы (PSMPATH) → device-файлы (DEVPATH, текущий
каталог) → компоненты → сети → геометрия.

## Device-файл

```
(DEVICE FILE: dev_r_0603 - used for device: 'dev_r_0603')

PACKAGE 'R-0603'
CLASS IC
PINCOUNT 2

PINORDER 'dev_r_0603' 1 2
FUNCTION G1 'dev_r_0603' 1 2

END
```

`PINCOUNT` обязан равняться числу пинов **символа**, иначе при создании
`ERROR SPMHGE-82` и компонент создаётся неразмещённым. Имя файла —
строчное имя устройства с `.txt`, рядом с платой (DEVPATH включает `.`).

## Компоненты

```skill
cc = axlDBCreateComponent("R1" "dev_r_0603" "R-0603" "10k")
axlDBCreateSymbol("R1" 10:20 nil 0)
```

`axlDBCreateSymbol(list(символ "package" refdes) …)` без логического
компонента возвращает nil молча (учебная плата: пустые платки).
Пины компонента собираются по его dbid: в списке `d->components`
в пакетной сессии у элементов пустые `refdes`/`name` — итерировать
по сохранённым dbid и брать `c->name` (не `c->refdes`).

## Сети

```skill
axlDBCreateNet("NET1")
axlDBAssignNet(pin_dbid "NET1")
```

`axlDBCreateNet` возвращает dbid, `axlDBAssignNet` — t на пин.

## Геометрия

* Контур платы — `axlDBCreateLine` по 4 сторонам
  `"board geometry/outline"`; замкнутый `axlPathStart`+CreatePath тоже
  читается как контур.
* Route keepout subclass'а «all» не существует — прямоугольник
  `"route keepout/<слой>"` на каждом etch-слое; иначе в .brd барьер
  молча не создаётся.
* EP-пад корпуса без пина в схеме — добавить в device-файл пин
  и назначить цепь отдельно (решение о посадке — инженерное).

## Чем подтверждено

Плата собрана целиком из нетлиста выгрузки схемы: все компоненты
размещены, отчёт нет-листа платы совпал со схемой попинно.
