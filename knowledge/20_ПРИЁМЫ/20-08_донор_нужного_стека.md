# Носитель нужного стека вместо правки сечения

Правка числа слоёв через axlXSection — ловушки (30-13). Надёжный путь:
**найти среди плат проекта донор с нужным стеком** (например,
TOP/INT1/INT2/BOTTOM у плат индикации), скопировать, зачистить:

1. `d = axlDBGetDesign()`, `axlDBIgnoreFixed(t)`, `axlVisibleDesign(t)`
   — видимость ВСЮ (иначе скрытые слои не выбираются, 20-05).
2. Медь и фигуры лишних — нет: донор уже 4-слойный; удалить всё:
   компоненты через `copy(d->components)` + Delete, сети
   `axlRemoveNet`, фигуры выборкой по категориям, зоны/keepin.
3. Остаются: стек, правила (матрица зазоров), падстеки, диэлектрики.
4. На носитель — свои компоненты/сети (10-07), планы рисуются
   прямоугольниками на etch-подклассах, барьер — route keepout
   по-слойно.

## Выбор донора

Стек смотреть `axlXSectionGet(nil 'all)` (поля `->name`, `->layerType`,
`->thickness`, `->material`) или `report -v x-section`. Проверить:
единицы (мм), матрицу зазоров (унаследуется! — при жёстких правилах
донора ослабить своей матрицей), диэлектрик между TOP и планом (для
Z0 диффпары: чем тоньше — тем уже проводник).

## Как неправильно

* Чистить «всё» фильтром без включения видимости — скрытая медь
  остаётся (20-05).
* Править стек готовой платы через Delete PLANE — молча nil (30-13).

## Чем подтверждено

4-слойный носитель собран из платы индикации (TOP 18 мкм / FR-4 0,335 /
INT1 35 мкм / FR-4 0,711 / INT2 35 мкм / FR-4 0,335 / BOTTOM 18 мкм):
после зачистки 0 компонентов/сетей/меди; на него перенесено размещение
169 корпусов и вся связность.
