# SES → плата без формы

Форма specctra_in может зависать надолго
([30-11](../30_ГРАБЛИ/30-11_формы_в_пакетном_режиме.md));
надёжный путь — разобрать SES и создать геометрию SKILL-ом.

## Формат (что нужно знать)

* `(wire (path LAYER WIDTH x1 y1 x2 y2 …) (connect …))` — проводник:
  координаты парами после ширины; единицы задаются
  `(resolution MM 10000)` и `write_resolution M 10000` — делить на
  10000 → мм.
* Переходные — **плоские** записи на уровне цепи, не внутри wire:
  `(via PADSTACK X Y)` (могут быть `(attr fanout)` и др.).
* Под `(network_out (Net 'ИМЯ' …))` — блоки по цепям; бывают `(shape …)`
  (полигоны меди) — создавать через axlDBCreateShape при
  необходимости.
* Терминалы `(connect (terminal smd R1.1))` можно не проверять —
  соединение обеспечивается точным попаданием конца проводника в пад.

## Создание

```skill
p = axlPathStart(list(x1:y1 x2:y2 …) 0.25)
axlDBCreatePath(p "etch/TOP" "NET1")      ; cline на цепи
axlDBCreateVia("VIA_PADSTACK" x:y "NET1") ; переходное
```

`axlDBCreatePath` с именем цепи создаёт cline на ней; точки —
координаты платы (мм). Ширина — третья колонка path (мм).

## Проверка

Числа созданного (проводники, переходные по слоям) сверяются с
количествами в SES; связность — DRC платы и отчёт по цепям
(`report -v net`): у каждой цепи пины+переходные в одной группе.

## Как неправильно

* Перебирать `(via …)` внутри каждого wire одной цепи — переходные
  дублируются на каждый проводник цепи.
* Брать координаты за миллиметры: они в единицах resolution.
* Создавать проводник без имени цепи и рассчитывать, что цепь
  «прилипнет» по касанию — цепь надо назначать явно.

## Чем подтверждено

Полная трассировка платы залита скриптом: счётчики проводников и
переходных по слоям совпали с сессией; вид сверху совпал с картинкой
трассировщика; DRC платы показал только ожидаемые зазоры.
