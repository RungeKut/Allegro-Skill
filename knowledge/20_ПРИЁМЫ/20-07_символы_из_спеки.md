# Посадочные из JSON-спеки

Спека: `{pads_new, pads_copy, pins [[num, x, y, pad, rot]...], silk, bound,
refdes}`. Пайплайн: шаблон .dra (в милах) → очистка → падстеки
(pads_new создать, pads_copy взять .pad с PSMPATH) → пины → шёлк/габарит
→ `axlCompileSymbol`. Координаты спеки — миллиметры, конверсия
`round(mm * 1000/25.4, 1)`.

## Центр символа = центр пинов

При реконструкции из чужого символа центрируйте пины по **среднему
координат пинов**, не по bBox символа: bBox включает шёлк и текст
(сдвиг пинов достигал 0,4 мм — у 2-выводных «пины пересекаются и
слишком близко»).

## Текст номера пина — textBlock 1

`make_axlPinText` с `?textBlock 2` (~2,5 мм) раздувает `pin->bBox` до
~1,25×2,8 мм: дамп пинов и DRC дают **фантомные пересечения падов**,
которых нет по меди. TextBlock 1 (~0,6 мм) убирает эффект.

## Границы посадки

`place_bound` = габарит меди пинов + 1,0 мм; `silkscreen` = +0,8 мм.
Габарит по bBox чужого символа (с шёлком) давал пересечения посадочных
прямоугольников.

## Чем подтверждено

29 символов собраны и применены на плате 169 корпусов; после перехода
на textBlock 1 и re-center фантомные DRC исчезли, остались только
реальные.
