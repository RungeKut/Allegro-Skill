# Доводка размещения через DRC-цикл

Прикидки зазоров по bBox пинов из выгрузки врут (bBox включает текст
номера пина — 20-07). Земля — DRC Allegro на пересобранной плате.

## Цикл

1. `ak.drc(плата)` → список нарушений с `Element 1/2` (там refdes).
2. Уникальные пары refdes; для пары «не-якорь ↔ что-угодно» — сдвинуть
   не-якорь от якоря на (порог − зазор) + запас; якоря (разъёмы, ИС,
   трансформатор) не двигаются.
3. Записать placement → пересобрать плату → повторять до нуля.

## Ориентация 2-выводных перед доводкой

Сигнальный вывод (цепь не из списка планов/шин: GND, +5V_ISO, +3.3V…)
смотрит на **центр своих партнёров**; план/шина партнёром не считается —
центроид сотен пинов GND по всей плате даёт мусорное направление.
Повороты: вывод 1 локально слева → rot 0 = влево, 90 = вниз, 180 =
вправо, 270 = вверх; для пары «план + сигнал» сигнал поворачивается к
партнёру, план в свободную сторону.

## Якоря и стагнация

* Пары «якорь-якорь» цикл не решает — раздвигать в исходной таблице
  размещения.
* Если за итерацию ничего не сдвинулось (зажатая пара) — сдвигать
  диагонально (по обеим осям) или отдавать на ручную доводку: остаток
  быстрее правится в GUI, чем алгоритмом.
* Отчёт писать в файл (список для ручной доводки в GUI).

## Чем подтверждено

169 корпусов: ориентация 89 2-выводных по цепям + 5 итераций DRC-цикла
снизили нарушения 229 → 65 (<0,18 мм); остаток — точечные развороты
для ручной доводки.
