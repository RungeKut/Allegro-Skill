# Фильтр выбора и видимость слоёв

`axlSetFindFilter` + `axlAddSelectAll` выбирают объекты только на
**видимых** слоях. Медь на скрытых внутренних слоях и выгрузка по
сегментам (`ak.dump` показывает 1000+ сегментов) после выборки «всё»
остаются нетронутыми — зачистка выглядит успешной, мусор остаётся.

## Как правильно

```skill
vis = axlVisibleGet()
axlVisibleDesign(t)               ; вся видимость
axlSetFindFilter(?enabled list("ALL" "NOPINS" "NOSYMBOLS" ...)
                 ?onButtons ...)
axlAddSelectAll()
; … удаление по objType («polygon», «path», «arc», «line», «text»)
axlVisibleSet(vis)                ; вернуть как было
```

Списки объектов из слотов дизайна (`d->components`, `d->nets`)
видимость не учитывают — выборкой выгодно пользоваться для фигур,
а компоненты и сети удалять прямыми dbid-проходами.

## Как неправильно

* Чистить по категориям фильтра без включения видимости и делать вывод
  об успехе по коду возврата: внутренние слои останутся.
* Удалять «всё выбранное» без разбора по `objType` — под `ALL` попадают
  и нужные классы.

## Чем подтверждено

Зачистка платы-донора: до включения видимости после выборки оставалось
~1500 сегментов меди на двух скрытых внутренних слоях; после — 0.
